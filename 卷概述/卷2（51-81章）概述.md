# 卷2（51-81章）概述

> 《食鼎权锋》第二卷 · **宴动曼哈顿**：从"一张网的中心"，走到"锅边的一个人"。

---

## 一、基本信息

- **章节区间**：第0051章 – 第0082章（现存 32 章；本卷规划至第0100章，为在写卷）
- **主要地点**：纽约（曼哈顿、唐人街、运河街）＋ 波士顿 ＋ 扬州（得胜桥）
- **时间跨度**：约十一个月（年初伯克筹款季 → 次年一月）
- **核心命题**：`食补` 系统化 ＋ `攻心` 的三种用法（政治、商战、人情）；并第一次学会**退**——退到水里、退到钝刀、退到承认"我没有那一分"。

---

## 二、主角轨迹

本卷是"**成网 → 用网 → 离网**"的完整弧线：

1. **扩张（51–60 章）**：从私宴走进市议会与学界——奥康纳（市议员）、罗森塔尔—韦克斯勒（西奈山）接连入场；波士顿落下两个点，"一口锅管两座城"。
2. **参战（61–68 章）**：波士顿伯川冷链事故，他第一次以"顾问"身份打一场商战，用**三层坏（制度／行为／人性）**先取证、后收网。
3. **露脸（69–70 章）**：周志明的家宴上留下"给华盛顿的空位"；两百人的筹款大席靠"每张卡片后面一个人"扛住。
4. **学艺（71–76 章）**：因沈砚秋一句话而南下扬州，放下用了十四年的薄刃刀，练钝刀、看水、学推汤，终于**凭自己的名字**入师门。
5. **认败（77–81 章）**：冬席比试连输三道；他把败局做成"菜"与人情，借势解开方济仁的并购案，最后放下"复刻沈砚秋的那一分"，从网的中心走到锅边——卷末点火，第一锅给阿彪、老刘头、艾琳。

## 四、关键人物（本卷新增／升格）

- **奥康纳**：纽约市议员，第七选区。清廉得近乎倔，土地审批改革全票通过；他背后的"厨子"第一次被人追查。
- **里卡多**：奥康纳的政治顾问，第一个从政纲里读出"有人教他"的人。
- **罗森塔尔 / 韦克斯勒**：医疗集团 CEO 与西奈山院长，为"食补进医院"开了一道门。
- **苏菲·陈**：资深营养师，以资质与规范为界挡下他的讲座——本卷最体面的对手。
- **魏伯川 / 弘文**：伯川冷链的正副，凌晨两点的冷库与一份被外购冰断掉的链条。
- **老麦**：制度之错下的中年人；"自己回来了"，是他对人的判断被验证的一次。
- **沈砚秋**：七十一岁淮扬名厨，"功夫不在灶上，在水里"；只给两个字——"像样"。
- **沈念**：沈砚秋的孙女，三天点拨一次，不多给。
- **白师傅**：八十岁的钝刀匠人，"借刀"一节的关节。
- **菲茨杰拉德**：波士顿市议员，凯伦引荐，波士顿线的新节点。
- **哈里森**：联邦参议员，两百人宴席上现身，与"留给华盛顿的空位"合流。
- **秦越**：卷01 十九章那碗"菜单外的汤"的旧客，本卷带并购案回来。
- **劳有年**：主角之父，已故。张庄人，早年帮过一个扬州师傅；卷01 第八章埋线，本卷 74／76／81 章收回。

## 六、伏笔与回收

- **已回收**：卷01 第八章老刘头"扬州有座桥，桥边的水不能急" → 74／76／81 章三次收束；卷01 第十九章"菜单外的第一碗汤"里的秦越 → 79／80 章的并购案；卷01 第四十二章老刘头两次提"你爹当年" → 81 章旧锅。
- **已回收（82章）**：苏菲·陈的调查（58 章"门只开一半"）→ 82 章出结果，条件是以后西奈山活动需苏菲签字备案，门开但留门框；周太太心结（13 章埋，69 章明写"她仍然不知道该不该让他知道"）→ 82 章以最坏方式炸开——律所背景调查卡住志远，他一个人坐在曼哈顿大堂里；周志明"将来有事找你"（14 章，81 章重提"那笔人情他还没有动"）→ 82 章周志明自己来还人情，不是求劳通天办事，是告诉他有人在查他。
- **仍悬着**：留给华盛顿的空位（69 章）；哈里森的联邦线（70 章）；北极星冷链（68 章）；沈砚秋来信"明年春天，得胜桥再见"（80 章）；打黑工旧报道（28 章，80 章已预热为公共桌面的刀）。
- **新埋下**：波士顿两个点（59 章）＋ 伯川顾问身份（68 章）＝ 卷03 的双城纵深；"锅边不再只有一个人"（81 章）＝ 团队化的开始；82 章网图背面写"起"字，志远在华盛顿画空心圈＝卷03 的入口已从"空位"变成"有人"。

## 七、卷末状态（截至 82 章）

- **网**：纽约（政／商／医疗／老钱／唐人街）＋ 波士顿 ＋ 华盛顿（志远的空心圈）；节点从三十个饭盒扩到两百人的席。
- **手艺**：从"味绝"进入"水路"——钝刀、看水、推汤；南北两味合流，有了自己的名字。
- **势**：奥康纳的改革落地，他的名字第一次被人追查；伯川顾问聘书在手；西奈山门开但留门框。
- **心**：输过一次比试，认过自己没有"那一分"，也第一次承认"网的有用不在中心的人聪明，而在边上的人肯接住别人"；周志明的还人情让他明白——人情不是债，是线，接上了就不再是悬着的。
- **代价与裂缝**：维多利亚、威廉等最脆弱的节点在离纽约期间同时出问题（卷01 末）；医疗圈的门只开一半；华盛顿在等；志远的前途第一次因父亲的背景被卡。
- **网图状态**：正面密不可分，背面写下"起"字。网从"铺"进入"起"。

> 下一卷（卷03，第0101章起）：**华盛顿的空位有人坐下了**——志远的背景危机、联邦级的饭局、波士顿纵深的商战，以及一张不再需要他当中心的网。
