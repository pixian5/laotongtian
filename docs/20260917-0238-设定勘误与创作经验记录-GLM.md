## 二、逐条记录

### 1. 人物异名：周坤鹏 → 周志明

**现象**
卷01 全篇把和胜堂老大、周太太的丈夫写作"周坤鹏"；卷02 全篇写作"周志明"，且明确写他是"纽约市议会议员"（第60章"这是我丈夫——周志明"）。同一个人，跨卷两个名字，而且从帮派老大到市议员的身份跃迁没有任何交代。

**定位**
- 卷01：第1章（人物速记）、第3、10、11、12、13、14、15 章。
- 卷02：第60章（正面出场）、第81章（"那笔人情，他还没有动"）。
- 附带的第二重问题：第13章的心结是"怕儿子知道父亲是帮派老大"，第69章写"志远还不知道父亲年轻时和和胜堂的关系"——这两处保证了"帮派出身"必须保留，不能只当作笔误删掉。

**判定依据**
第60章 51 行、第69章 43 行、第81章 217 行都指向同一人；`鹏哥`在两卷对话里共出现 40 余次，是他在唐人街的称呼，可保留为昵称。

**修法**
1. 卷01 与卷02 第81章的 `坤鹏` 一律替换为 `志明`（含第13章对话里单用的"坤鹏"）。
2. 保留 `鹏哥` 作为唐人街的称呼，并在第1章首次出现处点明："老大周志明，唐人街都叫他'鹏哥'"。
3. 第60章补一句来路，补上"帮派 → 政界"这一跃的因果：
   > 唐人街的老一辈还叫他"鹏哥"——和胜堂当年的老大；后来他把堂口一点点交了出去，人从侨社做进了市议会。

**教训**
跨卷写作时，"同一个人在不同卷里换了称呼/名字"是最难自查的一类错误，因为两卷各自内部都是自洽的。**每次开新卷前，先把上一卷的人名清单过一遍。**

### 2. 代际错乱：凯伦是母亲还是妻子

**现象**
审查意见（P0-1）曾把"凯伦是泰德的母亲"改成"妻子"，但改动只落在标签句上，旧稿的"母亲"痕迹整片留着：
- 第45章："你给我儿子做饭——我儿子肝坏了""你儿子？泰德是你儿子？""你出去。我跟我儿子说话。"
- 第46章："六十岁的女人——儿子肝快死了，她刚知道儿子喝了四年酒"（两处）
- 年龄：第45章"六十多岁，银发"、第48章"我六十岁了在纽约"、第49章"六十岁的脸"

**判定依据（为什么只能是"妻子"）**
1. 埃莉诺是泰德的母亲，有多处硬证据：第32章"脸型像她（埃莉诺）"、第35章劳通天对泰德说"你妈七十三"、第40章"你妈七十三，你三十八九"。
2. 所以凯伦不可能是母亲——否则泰德有两个母亲。
3. 直接写明是妻子的有：第45章"泰德的妻子，埃莉诺的大儿媳"、"我是他妻子——凯伦·范霍恩"；第48章"他有妻子——凯伦·范霍恩，在纽约。前妻——不联系"；第59章"她说你救了她丈夫——肝移植"。

**修法**
1. 第45章：外貌改"四十好几，鬓角白了几缕"；三处"儿子"对白全部改写（"你给他做饭——他肝坏了"、"我跟我丈夫说话"），并把原本"你儿子？"那个反应节拍换成劳通天的认领——"有。我给他做了半年菜——没看住他的肝。"
2. 第46、48、49章：年龄与"儿子"一并改作"四十好几／丈夫"；第48章"我六十岁了在纽约"改成"我又在纽约"（她要诉的是异地，不是年纪）。
3. 补一段交代两次婚姻，顺手解决三处连带疑问（他为何"离婚独居"、妻子为何当不了移植委员会要的"社会支持"、她为何因"紧急联系人不是自己"而失态）：
   > 第一次婚姻散了、孩子跟着母亲去了伦敦以后，他在纽约又结了一次。两个人各住一座城——她在纽约管她的家具生意，他在波士顿一个人守着 Beacon Hill 那栋三层小楼。谁也没提过搬到一起。
4. `他连他妻子都不留` → `他连我都不留`（妻子本人说话，人称更自然）。

**教训**
审查意见只给"结论"（改成妻子），不给"残留清单"。**采纳结论后必须把该人物的所有出现处重新过一遍**——标签改了、逻辑没改，等于把矛盾从"卷内显性"挪成"卷内隐性"，更难发现。判断"母亲/妻子/兄弟"这类关系，先找**不可反驳的锚点**（这里是"埃莉诺是母亲"），一次定死，再全量清洗。

### 3. 数字冲突：泰德的年龄

**现象**
第32章"三十八九岁"、第45章"三十八岁"、第49章"三十八岁"——但第32、35、39、40 章另有 8 处写作"四十多岁"（6 处）与"四十五岁"（2 处）。

**修法**
统一为**三十八九岁**（保留第32章的首次形象描写与第45章那句"三十八岁。肝硬化晚期。"的力度），改掉：
- 第35章："你四十多岁，不是二十多" → "你快四十了，不是二十多"；"他四十多岁了，身体确实不如三十岁" → "他快四十了，身体确实不如从前"
- 第39章："一个四十多岁的男人" → "一个三十八九岁的男人"；"你四十多岁……再喝十年，六十岁不到就是肝硬化" → "你三十八九……再喝十年，不到五十就是肝硬化"（**顺带修掉被连带影响的算术**）
- 第40章："你妈七十三，你四十多" → "你妈七十三，你三十八九"；"泰德是四十五岁的孤独" → "三十八九岁的孤独，是第一次婚姻散了、孩子被带走的孤独"
- 第32章："你妈七十三，吃清淡的。你四十多" → "你三十八九"

**教训**
改年龄不能只改数字：**任何依赖该数字的算术、对比句、外貌描写都要一起看**（"再喝十年就是肝硬化"、"身体不如三十岁"）。另外要顺带检查年龄差是否还站得住——凯伦若真是六十岁，一个三十八九岁的丈夫的婚配就会读成旧稿残留，这也是上面第 2 条年龄必须一起改的原因。

## 四、续写前的自查清单（可复用）

人物类
- 每个角色的**姓名**在本卷与上一卷是否一致？有没有昵称、旧名、正式名混用？
- 关系锚点（父/母/夫/妻/子女）是否指向唯一？**锚点要能用一句话举证。**
- 年龄、婚姻状态、子女去向是否与既有描写冲突？

数字与时间类
- 年龄、天数、票数、金额改一处时，是否检查了所有依赖它的句子（算术、对比、外貌）？
- 时间跨度（如"二十六天""两个半月"）在各章之间是否闭合？

名称类
- 是否有同姓同名、或仅差一字的角色（阿瑟·范霍恩 / 阿瑟·惠特莫尔；赵志明 / 赵启明）？首次出场是否做了区分？

文本类
- 有无角色说出"第X章"这类元叙事？
- 章节标题与正文内容是否匹配？文件名与正文 H2 标题是否一致？
- 章名是否重复？

常用命令（在仓库根目录执行）
```bash
# 人物异名/残留扫描
grep -rn "旧名" 卷01 卷02
# 元叙事残留（排除各章标题行）
grep -rnE "第[0-9]+章" 卷01 卷02 | grep -v "## 第"
# 文件名与正文 H2 标题是否一致
for f in 卷01/*.md 卷02/*.md; do b=$(basename "$f" .md); h=$(grep -m1 '^## ' "$f" | sed 's/^## 第[0-9]*章-//'); n=$(echo "$b" | sed 's/^[0-9]*章-//'); [ "$h" = "$n" ] || echo "MISMATCH: $f"; done
# 章名是否重复
ls 卷01 卷02 | sed 's/^[0-9]*章-//' | sort | uniq -d
```
