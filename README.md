# 《斩杀线·食鼎权锋》

> 一个把"美国斩杀线"讲成爆款的印度主播，被自己点燃的烈火烧穿人生；跌碎之后，靠一口铁锅从西雅图唐人街的洗碗池爬进白宫宴会厅，最终以厨子之身成为地下权力的核心掌控者。

**版本：0.0.2**（2026-10-11：全部大纲文件归入"大纲/"目录统一管理；0.0.1：全书重构为"两部十二卷600章"新架构，逐章详细概要全部完成）

---

## 一、作品定位

都市爽文 / 暗黑都市权谋文。主角**劳通天**，加尔各答吠舍（拜萨）商人家庭出身。

- **第一部《斩杀线》（第1-6卷，001-300章）**：留学梦碎 → 家业破产 → 半工半读 → 直播间编造"美国" → 莫迪站台的政治狂欢 → 五道裂缝连环爆、被体制做成替罪羊、持旧签证非法滞留美国——**"美国斩杀线"从概念变成他自己的现实**。
- **第二部《食鼎权锋》（第7-12卷，301-600章）**：厨艺是他唯一的武器——**味绝（敲门砖）→ 食补（掌控健康）→ 攻心（操控决策）**，以饮食为切口撕开美国顶层权力的铁幕，步步蚕食，从唐人街到白宫，最终以厨子之身坐上地下权力的第十三把交椅。第二部起增加女性角色（陈曼丽、夏洛特·阿斯特、卡米拉·刘易斯、苏菲·陈），互动暧昧旖旎但克制。

**铁律：不靠运气，不靠金手指，不靠系统/重生。** 每一步晋升都是精准计算后的必然结果，所有厨艺来自真实后厨经验。
