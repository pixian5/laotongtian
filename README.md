# 食鼎权锋

> 一个厨子，一口铁锅，从唐人街洗到白宫权力核心。

---

## 一、作品定位

纯正都市架空爽文 / 暗黑都市权谋文。主角劳通天，28岁抵美，身无分文打黑工，外表温润内敛，实则心思缜密到毫巅。厨艺是他唯一的武器——味绝（敲门砖）→食补（掌控健康）→攻心（操控决策），以饮食为切口撕开美国顶层权力的铁幕，步步蚕食，最终以厨子之身成为地下权力的核心掌控者。

**不靠运气，不靠金手指，不靠系统/重生。** 每一步晋升都是精准计算后的必然结果。所有厨艺来自真实后厨经验。

---

## 二、核心逻辑

**食物是人类最底层、最私密的需求。** 权力再大的人也要吃饭，也有健康焦虑，也有情感执念。厨子能接触到的，恰恰是这些人在最放松、最不设防时的状态。

- **味绝**：以极致厨艺敲开上流圈大门——让人吃一口就记住你
- **食补**：以药膳调理掌控目标健康——让人离不开你
- **攻心**：以饮食记忆操控目标情绪与决策——让人听你的

三步递进，从做菜到做人，从掌勺到掌权。

---

## 三、主角设定

- **劳通天**，28岁，山东张庄人，14岁入后厨，苦练厨艺14年
- 无背景、无金手指、无系统、无重生
- 外表温润内敛，实则心思极深，善于观察和布局
- 厨艺是他唯一的武器和盾牌
- 核心能力：味觉绝准、火候精控、药膳配伍、察言观色、借势布局

---

## 四、写作要求

### 创作规范

* 每章 **2000-4000 中文字符**，每章写完即推送。
* 所有厨艺描写基于真实后厨经验，不编造不存在的烹饪技法。
* 权谋逻辑自洽，每一步晋升都有完整因果链，不靠运气跳跃。
* 保持原文剧情，扩写只丰富场景、细节、人物表现和叙事呈现，不改变既定事件走向和人物关系。
* 人物声音一致，每个角色的说话方式、性格特征和行为逻辑前后一致。
* 章节之间要有自然过渡，开头承接上文，结尾留下悬念、冲突或余韵。

### 标题与文件名格式

标题格式统一：`第000X章-关键词`，使用阿拉伯数字，如 `第0001章-序言`。
文件名格式统一：`0001章-序言.md`。
卷名格式统一：`卷01`。

### 每章完成后的检查与 Git 流程

每修改完成一章，立即检查章节长度、剧情连续性、人物一致性、厨艺真实性和权谋因果；确认无误后立即执行 `git add`，使用中文 commit 信息提交并立即 `git push`。不得在多章完成后再批量提交。
在目录“卷概述”里为每卷内容创建一个概述文件，文件名格式“卷1（1-50章）概述.md”；

### 重大问题记录

如果发现重大剧情漏洞、设定问题或重要创作经验，同步记录到 `docs` 目录对应的 `.md` 文件。
