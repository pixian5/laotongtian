# 《斩杀线·食鼎权锋》全书总纲

> **一句话故事**：一个把"美国斩杀线"讲成爆款的印度主播，被自己点燃的民粹烈火烧穿了人生，跌碎到不能再碎之后，靠一口铁锅和一罐玛萨拉香料，从西雅图唐人街的洗碗池爬进白宫的宴会厅，最终以厨子之身坐上美国地下权力的第十三把交椅。

- **类型**：都市爽文 / 暗黑都市权谋文
- **结构**：两部十二卷，每卷50章，共600章。第一部《斩杀线》（第1-6卷，001-300章），第二部《食鼎权锋》（第7-12卷，301-600章）。**章节序号全书顺延，各部不重新起号。**
- **铁律**：不靠运气、不靠金手指、不靠系统、不靠重生。每一次跃迁都必须展示完整的因果链：他手里有什么牌、缺什么牌、从谁手里拿、付出什么代价。

## 一、主题与母题

**1. 斩杀线的定义（全书题眼）**：任何系统都有一条隐形资源线——线上的失效会被系统修复，线下的失效会被系统回收。跌破斩杀线的人不是变穷，而是变成耗材：他的痛苦不再产生成本，他的消失不再产生新闻。劳通天在直播间里发明这条线，在印度被这条线清零，最后在美国成为画这条线的人。**全书首尾闭环：他从线的宣讲者，变成线的执笔者。**

**2. 大循环（第一部收束）**：美国梦失败 → 回印度 → 家业破产 → 再赴美国 → 留学失败 → 直播成名 → 政治崛起 → 被政治抛弃。他天天向观众宣判别人跌破斩杀线，最后在故乡被制度一键清零——他的命运就是他自己吹出来的故事，只是那个"美国"叫印度。

**3. 镜子结构**：全书大量使用镜像场景——第一次赴美与第二次赴美（商务舱与经济舱）、第一次表演美国（婚宴分享会）与最后一次表演美国（白宫国宴）、莫迪利用他与圆桌俱乐部利用他、他被粉丝抛弃与曼丽在他最穷时为他挡ICE、第001章与第600章（同样面对一个底层留学生后辈）。每个高潮都要找到它的镜子。

**4. 道具母题**：
- **玛萨拉罐**：母亲塞给他的自制香料，三次出现（卷2离别、卷4泪崩直播、卷12尾声）。
- **直播设备**：环形灯、支架、两个行李箱——卷5存进西雅图自助仓储，卷6取出（"从哪来回哪去，连道具都没换"），卷7被当废品贱卖前他留下了那盏环形灯（后来挂在鼎灶后厨）。
- **表格癖**：他一生都在做表——伪造成绩单模板、带货配比表、锚点库、"嫁美国"可行性表、餐桌档案。做表是他的天赋也是他的罪证。
- **ICE僵住**：每次听到移民执法局（ICE）相关动静，他会僵住几秒——这个反应直到第540章拿到绿卡才消失。反差感的核心装置：白宫宴会厅的鎏金与他的手心汗同框。

**5. 讽刺内核**：他最想学会的英语没学会，最不需要的日语学得最好；他靠印度的"关系传统"（行贿）保住学籍，又靠同一种传统智慧（揣摩胃口）在美国登顶；他骗观众说美国有"格斗场换床位"，最后自己在现实中住过比那更糟的地方。

## 二、主角深度设定

**劳通天**，本名拉坦·劳（Ratan Rao），1990年生于加尔各答，吠舍（拜萨）商人家庭。英语烂、日语好、中文是后来自学的（唐人街时期）。"通天"是他给自己起的中文昵称——寓意直通天花板，这个满是欲望的名字后来成了他的品牌。

**能力面板（全部有来历，无一是天降）**：
- **揣摩人心**：直播时代练成——四年时间每天读几万条弹幕，他知道每一种愤怒、每一种渴望长什么样。这是他最锋利的武器，比厨艺锋利。
- **造假与锚点**：编故事的天赋+工程师式的自控——每个谎言必须配两个可验证的锚点（真实新闻、真实地名、真实账单），让观众自己完成"他说的应该是真的"这最后一跃。
- **香料与味觉**：母亲苏妮塔的家传玛萨拉配方+印度自助餐厅后厨的两年打磨+对"美国人味蕾"的商业级洞察（美国人怕的不是辣，是陌生；要的不是正宗，是故事）。
- **厨艺**：卷7起在金门酒家从零苦练——老刘头教的钝刀与吊汤、洋葱三百斤的血泡、十二席实验里烧出来的火候。所有厨艺来自真实后厨经验，不编造不存在的技法。
- **做表与档案**：Excel式的头脑，把人变成行、把饭局变成数据库。

**心理底盘**：自卑与表演型人格的合金。他对权力的理解全部来自被权力碾过的经验——所以他不怕权贵，怕移民局；他能在参议员面前谈笑，会在看见ICE警车时僵住。这种错位贯穿全书，直到最后也不许"治愈"，只允许"覆盖"。

## 三、权力方法论（第二部主干）

**味绝（敲门砖）→ 食补（掌控健康）→ 攻心（操控决策）**，对应卷8、卷9、卷10-12三段跃迁：

1. **味绝**：让人吃一口就记住你。富人买的不是菜，是身份、安全与被记得的感觉。配套"三不原则"（不拍照、不带手机、不问主人是谁）建立保密信任。
2. **食补**：以食药同源的调理掌控目标的健康与日程——让人离不开你。科学底座：姜黄素配黑胡椒碱的生物利用率、低FODMAP、发酵饮食，全部有据可依，不玄学。
3. **攻心**：以饮食记忆操控情绪与决策，以餐桌情报操控局面——让人听你的。核心资产是**餐桌档案**：谁和谁喝了两瓶、谁提前离席、谁的手机反扣、谁多看了一眼账单。**"厨房是最后一个没被监控的房间。"**

**技能平移表（第一部→第二部的暗线，写作时要点到）**：读弹幕→读餐桌；锚点库→菜单里埋真实新闻梗；人设工程→主厨口碑工程；带货话术→谈判话术；喂观众→喂情报；被MCN抽成→被俱乐部抽成；被莫迪用→被圆桌用。**他本质没变：揣摩别人的胃口，换取生存筹码。**

第二部起增加女性角色。**暧昧旖旎但克制**：好感产生于利益与才华的碰撞，升温于深夜厨房、天台、打烊后的茶；**止于将触未触**——可以有对视、递茶、替他挡事、婚礼上的一句敬酒词，不许有露骨情节，不许随口许诺。女性角色不是奖品，是权力场里独立的玩家：曼丽要的是对等的合伙人，夏洛特要的是不被算计的真话，卡米拉要的是谁能办事，苏菲·陈要的是证据。劳通天在感情上永远"差一步"——不是不敢爱，是他清楚地知道：**一个随时会被遣返的人没有资格开始**。第540章绿卡到手后，他依然不敢——这个不敢，是全书最后的余味。

## 六、十二卷弧线节拍（逐章概要的唯一依据）

### 第一部《斩杀线》

## 七、文风与格式铁律

1. 每章概要=标题独占一行+一整段正文（段内不换行、不分点），210-270个汉字。
2. 每章必须含"场景+人物动作+冲突/转折+章末钩子"，至少两个具体名词级细节（人名、菜名、地名、金额、机构名）。
3. 禁止空洞句（"他们经历了很多""发生了意想不到的事"）；禁止形容词堆砌替代具体事件。
4. 都市爽文的节奏纪律：小爽点每3-5章一个（救场、反杀、打脸、进阶），大爽点每卷末一个；每个大爽点前必须先压到位——压得越狠，爽得越真。
5. 暗黑权谋的底线：所有阴谋必须符合逻辑与代价，主角可以有黑暗手段，但必须付出对等成本或留下对等隐患；反派永远不蠢，只是格局输一层。
6. 政治讽刺尖锐但不流于谩骂；涉及真实国名与真实人物（莫迪）时，用小说化处理，讽刺指向体制逻辑而非民族。
7. 全书章节号顺延：第001章至第600章，任何一卷不得重新起号。
